# Sasha & Masha | Мониторинг бюджета

Локальный сайт семейного FCF: загрузка справки Т-Банка и аналитика без Excel.

## Запуск

```bash
cd site
chmod +x start.sh
./start.sh
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765).

План и факт января–июля подтягиваются из `16.08.2026_Бюджет 2026.xlsx`. Дальше правки живут в `site/data/budget.sqlite`.

## Как обновлять месяц

1. Раздел **Загрузка данных**.
2. PDF «Справка о движении средств» с общего счёта.
3. Проверить авторазнос, поправить статью у спорных операций — сайт запомнит магазин.
4. **Записать месяц в факт**.
5. Раздел **Аналитика** — курсы ЦБ, графики, выводы и рекомендации пересчитаются.

Первую сверку закладывали на закрытие августа: справка от 16.08 ещё неполный месяц.

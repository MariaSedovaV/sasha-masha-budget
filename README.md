# Sasha & Masha | Мониторинг бюджета

Семейный дашборд FCF: аналитика, вклад (разделение денег и недвижимости), загрузка справки Т-Банка.

Публичная ссылка: https://mariasedovav.github.io/sasha-masha-budget/

## Открыть на компьютере

```bash
cd site
chmod +x start.sh
./start.sh
```

Сайт: [http://127.0.0.1:8765](http://127.0.0.1:8765)

## Вкладки

- **Аналитика** — курсы ЦБ, кумулятив FCF, факт против плана
- **Вклад** — накопления Саши и Маши и доли в недвижимости
- **Данные** — PDF, категории, сетка факта (только на локальном сервере)
